# Apple-Minimal Responsive Web MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the `web/` (Vite + React) surface of SanBayGo as a single responsive codebase that serves the Input → Comparison → Detail flow at mobile (≤ 768 px), tablet (769–1024 px), and desktop (≥ 1025 px), using an Apple HIG-inspired token system (`#007AFF` accent, neutral `#FAFAFA`/`#FFFFFF`/`#1C1C1E`, hairline separators, no gradients/glass/warm tones) that **also** replaces the existing `ResultDisplay` glassmorphism direction on the web side.

**Architecture:** Stand up a new top-level `design-system/` module parallel to `core/`, holding **only** token primitives (no glass tiers). The module is consumed by `web/` via a new `@design-system` path alias and emits:
- CSS custom properties (`design-system/tokens/index.css`) — palette, typography scale, spacing, radii, shadow tokens.
- A typed JS object (`design-system/tokens/index.ts`) — same values, used by Tailwind's `theme.extend.colors` in web.

RN-side (`components/ResultDisplay`, `components/VehicleComparison`) is **out of scope for this plan** — the SDD task `task-8a-brief.md` already kicked off the RN side via the glassmorphism direction, and we are **deliberately superseding the visual direction for both platforms** by deleting the glass + warm-palette decisions from `web/` and replacing them with Apple-minimal tokens. RN updates land in a follow-up plan.

**Tech Stack:** Vite + React + TypeScript (existing), ts-jest + `@testing-library/react` (existing), `@testing-library/jest-dom`, `@playwright/test` (existing), plain CSS Modules (no Tailwind added — the user's web MVP already uses CSS Modules; tokens land as CSS vars so they can also be referenced from CSS Modules without a Tailwind migration).

## Global Constraints

- **Vietnamese UI text** for any user-visible string on `web/`. The existing `web/src/contexts/LanguageContext.tsx` (vi/en) is preserved.
- **No new dependencies unless absolutely necessary.** No Tailwind, no `shadcn/ui`, no `module-resolver` Babel plugin. Tokens via CSS vars + a TS object.
- **Single source of truth for design tokens.** `design-system/tokens/tokens.ts` (TS) + `design-system/tokens/tokens.css` (CSS) are generated by hand from the same source table in this plan — they MUST match exactly. Both files live in the same directory and a unit test (Task 4) pins parity.
- **No gradients, no glass, no warm tones, no purple/cyan, no shadows beyond the hairline shadow token** (`0 1px 2px rgba(0,0,0,0.04), 0 0 0 0.5px rgba(0,0,0,0.06)`). The accent is `#007AFF` and it is rationed: only CTA, active step indicator, recommended-card left edge, and brand mark.
- **Typography scale is fixed:** body 17, secondary 13, caption 11, section 22, display 28, hero 34, page-title 40 — all in `pt`-equivalent px. Body must be ≥ 17 px (no AI-templated 14-px body).
- **Hairline separator token:** `0.5px solid rgba(60, 60, 67, 0.12)`. Use everywhere instead of border-bottom with darker color.
- **Touch targets ≥ 44 px** on mobile.
- **Responsive breakpoints:** mobile ≤ 768 px, tablet 769–1024 px, desktop ≥ 1025 px.
- **System font only** — `-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", system-ui, sans-serif`. No Google Fonts.
- **No emojis as functional icons.** All icons are inline SVG (SF-symbol-style). Existing ⚠️ emoji in `ResultDisplay` is replaced by a `WarningIcon` SVG.
- **`@core` API surface is unchanged** — `calculateTripComparison`, `sortComparisons`, `ArrivalResult`, `ArrivalFormData` types already exported from `core/calculation-engine` and `core/types`. We consume them, do not modify them.
- **`init.sh` must remain green.** All `tsc --noEmit` and `npm test` runs (root, `core/`, `web/`) continue to pass. The new `design-system/tsconfig.json` is included in `init.sh`'s pre-flight after Task 1.
- **Web tests stay in `web/__tests__/`.** Jest config already covers `__tests__/` dirs; we add `web/__tests__/design-system/*.test.ts` for token parity.

| `--color-separator-strong` | `rgba(60, 60, 67, 0.20)` | Section divider |
| `--color-accent` | `#007AFF` | Single accent — CTA, brand, active |
| `--color-accent-pressed` | `#0051D5` | Hover/active CTA |
| `--color-accent-tint` | `rgba(0, 122, 255, 0.08)` | Recommended row fill |

## Typography

System font: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", system-ui, sans-serif`.

| Token | px | Use |
|---|---|---|
| `--font-size-caption` | 11 | Eyebrow labels, table headers (uppercase tracked) |
| `--font-size-secondary` | 13 | Subtitle, note text |
| `--font-size-body` | 17 | Body, form values |
| `--font-size-section` | 22 | Section headings |
| `--font-size-display` | 28 | Card titles |

- ✅ All body font sizes ≥ 17 px.

import { useEffect, useState } from 'react';
import { tokens } from '@design-system';

export type Viewport = 'mobile' | 'tablet' | 'desktop';

function readViewport(width: number): Viewport {
  if (width < tokens.breakpoint.tablet) return 'mobile';
  if (width < tokens.breakpoint.desktop) return 'tablet';
  return 'desktop';
}

export function useViewport(): Viewport {
  const [viewport, setViewport] = useState<Viewport>(() =>
    typeof window === 'undefined' ? 'mobile' : readViewport(window.innerWidth),
  );

  useEffect(() => {
    const onResize = () => setViewport(readViewport(window.innerWidth));
    window.addEventListener('resize', onResize);
    return () => window.removeEventListener('resize', onResize);
  }, []);

  return viewport;
}

    </div>
  );
}

  const { formData, updateFormData, reset } = useFormState();

  const handleCalculate = () => {
    if (!formData.terminal || !formData.baggage || !formData.destination) return;
    const calc = calculateResult({
      arrivalTime: formData.arrivalTime,
      terminal: formData.terminal,
      baggage: formData.baggage,
      destination: formData.destination,
      flightType: formData.flightType,
    });
    if (calc) {
      setResult(calc);
      setView('result');
    }
  };

  const handleRecalculate = () => {
    reset();
    setResult(null);
    setView('form');
  };

  const shell = (
    <div className={styles.app}>
      {viewport === 'desktop' ? (
        <div className={styles.desktop}>
          <Sidebar />
          <main className={`${styles.main} ${styles.mainDesktop}`}>
            <Header />
            <div className={styles.contentDesktop}>
              {view === 'form' ? (
                <ArrivalForm formData={formData} onUpdate={updateFormData} onCalculate={handleCalculate} />
              ) : (
                result && <ResultDisplay result={result} formData={formData} onRecalculate={handleRecalculate} />
              )}
            </div>
          </main>
        </div>
      ) : (
        <div className={styles.mobileShell}>
          {viewport === 'mobile' ? <TopBar title="SanBayGo" /> : <TabletTopBar />}
          <main className={`${styles.main} ${viewport === 'mobile' ? styles.mainMobile : styles.mainTablet}`}>
            {view === 'form' ? (
              <ArrivalForm formData={formData} onUpdate={updateFormData} onCalculate={handleCalculate} />
            ) : (
              result && <ResultDisplay result={result} formData={formData} onRecalculate={handleRecalculate} />
            )}
          </main>
        </div>
      )}
    </div>
  );

  return shell;
}

export default function App() {
  return (
    <LanguageProvider>
      <AppContent />
    </LanguageProvider>
  );
}
