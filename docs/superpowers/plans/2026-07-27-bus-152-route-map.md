# Bus Route Map Visualization - Tuyen 152

**Status**: Draft
**Labels**: ready-for-agent, enhancement
**Created**: 2026-07-27

## Problem Statement

Người dùng SanBayGo cần xem lộ trình chi tiết của tuyến xe buýt 152 để:
- Biết tuyến đi qua những điểm nào
- Hiểu mình sẽ xuống ở trạm nào
- Có trải nghiệm visual ấn tượng, khác biệt so với các app booking xe

Hiện tại app chỉ hiển thị thông tin text về giá/giờ, không có visualization cho tuyến đường.

## Solution

Component `RouteMap` hiển thị tuyến 152 dưới dạng **metro-style line diagram**:
- Tuyến đường được vẽ bằng SVG path (đường gấp khúc)
- Các điểm dừng là nút tròn trên tuyến
- Animation draw-line khi expand
- Toggle được giữa lượt đi và lượt về
- Highlight điểm đến (destination) của user

## User Stories

1. **As a user**, I want to see the full route map of Bus 152, so that I understand which stops the bus passes through

2. **As a user**, I want to expand/collapse the route map, so that I can save screen space when I don't need the detail

3. **As a user**, I want to see the outbound route (KDC Trung Son → SGN), so that I know the route direction

4. **As a user**, I want to flip to the return route (SGN → KDC Trung Son), so that I can see the reverse direction

5. **As a user**, I want to see my destination stop highlighted with animation, so that I immediately know where to get off

6. **As a user**, I want to see a draw-line animation when the map appears, so that the visualization feels polished and engaging

7. **As a user on mobile**, I want the route map to fit on my screen without horizontal scrolling, so that I can read all stops comfortably

8. **As a user**, I want to see the airport (SGN T3) and Ben Thanh hub marked distinctly, so that I recognize key landmarks

## Design Language

### Aesthetic
Metro-style line diagram (inspired by Tokyo Metro, Singapore MRT maps)
- Clean, geometric, modern
- Flat design - no 3D, no shadows on the line itself

### Color Palette
| Token | Value | Usage |
|-------|-------|-------|
| `brand-primary` | `#F97316` (orange-500) | Main route line, dots |
| `brand-dark` | `#EA580C` (orange-600) | Active/highlighted states |
| `text-primary` | `#1E293B` (slate-800) | Stop names |
| `text-secondary` | `#64748B` (slate-500) | Secondary info |
| `bg-surface` | `#FFFFFF` | Card background |
| `bg-muted` | `#F8FAFC` (slate-50) | Section background |

### Typography
- Stop names: 14px, medium weight
- Hub labels (SGN, Ben Thanh): 16px, semibold

### Spacing
- Vertical spacing between stops: 48px
- Horizontal padding: 24px
- Line stroke width: 3px

### Icons
- All stops: 12px filled circle (`●`)
- Hub stops (SGN, Ben Thanh): 16px circle with border
- Destination highlight: 20px with pulse animation

### Animation
- **Draw line**: SVG stroke-dashoffset animation, 800ms ease-out
- **Dots appear**: Fade in staggered, 50ms delay between each
- **Destination pulse**: Infinite subtle scale animation (1.0 → 1.1 → 1.0), 2s cycle
- **Expand/collapse**: Height transition, 300ms ease-in-out

## Component Specifications

### ExpandableRouteSection
- **Default state**: Collapsed, shows "Xem lộ trình tuyến 152 ▼" button
- **Expanded state**: Shows full RouteMap component
- **Transition**: Max-height animation or CSS grid rows

### DirectionToggle
- Two buttons: "Hướng đi" | "Hướng về"
- Active state: filled background
- Inactive state: outline only
- On switch: route map redraws with new direction

### RouteMap (SVG)
- **Dimensions**: Responsive width, height based on stops
- **ViewBox**: Auto-calculated based on stop positions
- **Padding**: 40px all sides
- **Line style**: stroke-width: 3, stroke: brand-primary, stroke-linecap: round

### StopDot
- **Base size**: 12px diameter
- **Hub size**: 16px diameter with 2px white border
- **Terminal size**: 16px diameter, filled
- **Destination size**: 20px diameter with pulse animation
- **Color**: brand-primary (filled), white (hub border)

### StopLabel
- Positioned to the right of dots (or left for right-side stops)
- Font: 14px, medium
- Alignment: left-aligned text

### Animation Implementation
- CSS `@keyframes` for pulse animation on destination
- SVG `stroke-dasharray` + `stroke-dashoffset` for draw-line effect
- Use CSS `animation-delay` for staggered dot appearance

## Implementation Decisions

1. **Pure CSS/SVG** - No external charting library. SVG is perfect for this use case.

2. **Grid-based positioning** - Stop positions defined as (x, y) grid coordinates. SVG path connects them in sequence. No complex layout algorithms needed.

3. **Responsive width** - SVG uses `viewBox` with `preserveAspectRatio`. Width via CSS `100%`.

4. **No external map tiles** - This is the key insight: metro maps don't need geographic accuracy. Straight lines and 90° angles are more readable anyway.

5. **Single SVG element** - One SVG containing both the path and all dots. Allows unified animation.

## Testing Decisions

### Test External Behavior Only
- Component renders with correct number of stops
- Direction toggle switches displayed route
- Expandable section shows/hides correctly
- Destination stop has highlight class applied

### Do NOT Test
- Animation timing (brittle, visual only)
- SVG path generation details (implementation)
- Specific pixel positions

## Out of Scope

- Geographic accuracy (intentional - metro style is abstract)
- Multiple bus routes on same map
- Real-time tracking
- Offline map caching
- Interactive stop selection (only highlighting, not clicking)

## Further Notes

This feature is purely visual enhancement. The underlying route calculation logic remains unchanged.

Consider this a pattern that could apply to other bus routes (Bus 86, Bus 109) in the future.
