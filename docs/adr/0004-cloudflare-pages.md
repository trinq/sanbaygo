# ADR-0004: Cloudflare Pages Deployment

**Status:** accepted (supersedes ADR-0003 VPS Deployment)
**Date:** 2026-08-02
**Deciders:** SanBayGo Agent + Human

---

## Context

ADR-0003 chọn **VPS + nginx + GitHub Actions rsync** làm deployment stack. Sau
~5 ngày hoạt động ổn định, những hạn chế của mô hình tự host đã trở nên rõ:

1. **Edge latency.** Server ở Singapore (VPS gần nhất cho VN users). Users ở
   Hà Nội / TP.HCM ping ~50-80ms. Cloudflare edge network có POP ở
   Hà Nội / TP.HCM → latency <10ms.
2. **Tự quản lý server.** Security updates, nginx config, Let's Encrypt
   renewal, monitoring — tất cả phải tự làm. SanBayGo không có on-call.
3. **Single point of failure.** Nếu VPS down → site down. Không có failover.
4. **Cost.** VPS ~$5-10/month cho traffic thấp, nhưng đó là recurring cost
   cho một side project.
5. **Atomic deploys.** rsync ghi đè files trong khi nginx đang serve →
   có thể serve nửa cũ nửa mới ~1-2s.

Mục tiêu migration: **giảm operational burden** và **tăng performance** mà
không mất tính đơn giản.

---

## Decision

**Cloudflare Pages** với `www.frylane.com` là canonical domain.

### Deployment Stack

| Layer | Technology | Notes |
|---|---|---|
| Hosting | Cloudflare Pages | Static SPA hosting, edge CDN global |
| CDN | Cloudflare (built-in) | POP ở Hà Nội / TP.HCM / Singapore |
| SSL | Cloudflare (auto) | Universal SSL, auto-renew |
| CI/CD | Cloudflare Pages GitHub integration | Auto-deploy on push to `main` |
| Build location | Cloudflare build workers | `npm ci && npm run build` |
| Atomic deploys | Cloudflare Pages | Staging preview URL trước khi promote |
| Custom domain | Cloudflare Registrar (apex + www) | Free Whois privacy, cost = TLD price |

### Directory Structure

```
# Trên Cloudflare Pages — không cần truy cập FS
# Build output (Vite dist/) tự được serve

# Local repo
web/
  ├── src/
  ├── public/sitemap.xml    # Generated by Vite plugin → commit OK
  └── dist/                 # Generated by build → gitignored
```

### CI/CD Flow

```
git push origin main
  → GitHub webhook → Cloudflare Pages
  → CF build worker: cd web && npm ci && npm run build
  → CF Pages atomic swap to new deployment
  → Preview URL (auto): https://<hash>.sanbaygo.pages.dev
  → Production (if auto-promote enabled): https://www.frylane.com
```

### DNS Configuration

| Type | Name | Content | Proxy |
|---|---|---|---|
| CNAME | `www` | `sanbaygo.pages.dev` | Proxied |
| CNAME | `@` | `sanbaygo.pages.dev` | Proxied (CF flattens to A) |
| Page Rule | `frylane.com/*` | → `https://www.frylane.com/$1` | 301 Permanent |

`www` là canonical. Apex `frylane.com` 301-redirect sang `www`. SEO
canonical URL = `https://www.frylane.com/`.

### Cloudflare Pages Settings

| Setting | Value | Notes |
|---|---|---|
| Production branch | `main` | Auto-promote on push |
| Build command | `cd web && npm ci && npm run build` | |
| Build output directory | `web/dist` | |
| Root directory | (empty) | Repo is small, keep at root |
| Node version | 20 | Match local dev |
| Environment variables | (none) | Client-side only, no secrets |

### GitHub Actions Workflow

`.github/workflows/deploy.yml` cũ (VPS rsync) **bị xóa hoàn toàn**. Cloudflare
Pages dùng webhook riêng — không cần GitHub Actions cho deployment.

Local dev workflow không thay đổi: `npm run dev` vẫn chạy Vite local.

## Considered Options

### Option A — Cloudflare Pages ✅ (chosen)

**Pros:**
- **Free tier** — Unlimited requests, 500 builds/month, 100k files/build
- **Edge CDN global** — POP ở Hà Nội (HAN), TP.HCM (SGN), Singapore (SIN)
  → latency <10ms cho VN users
- **Atomic deploys** — không bao giờ serve nửa cũ nửa mới
- **Preview URLs** — mỗi commit có preview URL riêng để test trước khi promote
- **Auto SSL** — Universal SSL + auto-renew, không cần certbot
- **Zero ops** — không có server để bảo trì, security updates, monitoring
- **GitHub integration** — connect 1 lần, auto-deploy forever
- **Cost** — $0 cho traffic hiện tại (static SPA)

**Cons:**
- Vendor lock-in (CF Pages) — nhưng dist/ là static, có thể move dễ
- Hạn chế server-side rendering — không phải vấn đề vì SPA thuần
- Build time limit 20 minutes — đủ cho project này (~3-5s)

### Option B — Giữ VPS (ADR-0003 status quo)

**Pros:**
- Đã setup sẵn
- Full control
- Quen thuộc

**Cons:**
- Single point of failure
- Manual SSL renewal
- Không có CDN edge
- Tự quản lý security patches
- Recurring cost

### Option C — Vercel

**Pros:**
- Zero-config
- Edge CDN
- Free tier 100GB bandwidth/month

**Cons:**
- CF free tier unlimited — Vercel có cap
- Ít POP ở VN hơn CF
- Lock-in với Next.js ecosystem (mặc dù static SPA OK)

### Option D — Netlify

Tương tự Vercel. Free tier không cho commercial use → loại.

### Option E — AWS S3 + CloudFront

**Pros:**
- Rất rẻ
- Full control

**Cons:**
- Setup phức tạp hơn nhiều (CloudFront, ACM, Route53, S3 buckets)
- Không có atomic deploys native
- Quá nhiều moving parts cho 1 static SPA

## Consequences

### Positive

- **Latency giảm** từ ~50-80ms (VPS Singapore) xuống ~5-10ms (CF edge HAN/SGN)
- **Uptime** tăng — CF Pages SLA 99.99% vs VPS thường 99.5-99.9%
- **Build/deploy workflow đơn giản hơn** — không có SSH key, rsync config, GH secrets
- **Preview URLs** — mỗi PR có URL riêng để share cho stakeholders
- **Zero recurring cost** — CF Pages free tier đủ dùng lâu dài
- **Không còn security updates** — CF lo

### Negative / Trade-offs

- **Vendor lock-in.** CF Pages build config là Cloudflare-specific. Nếu muốn
  move → phải viết lại deploy script. Mitigation: `dist/` là static → chỉ
  cần upload lên S3/Vercel/Netlify khi move.
- **Build minutes cap.** Free tier 500 builds/month, 20 min mỗi build. Hiện
  tại ~30 commits/month → 30 builds → 6% cap. Không vấn đề.
- **Custom domain phải qua CF Registrar hoặc external.** Nếu domain ở
  provider khác → CNAME phức tạp hơn. Đã move `frylane.com` qua CF Registrar
  để đơn giản hóa DNS.

### Migration Steps Executed (2026-08-02)

1. ✅ Mua domain `frylane.com` qua Cloudflare Registrar (~$10/year)
2. ✅ Cloudflare Pages → connect GitHub repo `trinq/sanbaygo`
3. ✅ CF Pages build config: build cmd `cd web && npm ci && npm run build`,
   output dir `web/dist`
4. ✅ Custom domain `www.frylane.com` → CNAME flatten to `sanbaygo.pages.dev`
5. ✅ Apex `frylane.com` → 301 redirect to `www.frylane.com`
6. ✅ Verify `https://www.frylane.com/` returns 200 with `server: cloudflare`
7. ✅ Delete `.github/workflows/deploy.yml` (VPS rsync) — no longer needed
8. ✅ Deprecate VPS — stop paying

### Deferred

- **Analytics** — Cloudflare Web Analytics (free, privacy-friendly) — add khi cần
- **Cloudflare Access** — auth wall cho staging nếu cần protect preview URLs
- **Rate limiting** — CF Rules → nếu bị abuse traffic
- **Cloudflare Workers** — nếu sau này cần server-side logic (ví dụ
  dynamic sitemap, geolocation redirect)
